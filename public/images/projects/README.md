# Project screenshots

Add your real project screenshots to this folder.

Recommended filenames:

- workpilot-dashboard.png
- datapilot-dashboard.png
- bazaarpilot-dashboard.png
- enterprise-knowledge-assistant.png
- rag-pdf-assistant.png
- movie-recommender.png
- online-car-booking.png

Then set the corresponding `image` field in `data/projects.ts`.

Do not commit screenshots containing API keys, private user data, passwords, tokens, or other sensitive information.
